# 正面图补齐三向视图

这份 Skill 只处理一种工作流：用户已经有一张确认过的**正面角色基准图**，需要补齐左／背／右三个方向。正面图本身就是四视图中的正面，不重新生成或替换。

通用模型查询、Runware 参数、内容输入和输出下载规则仍以 `runware` Skill 为准；不要在这里重复工具说明。

## 适用前提

- 用户明确指定一张正面基准图。
- 角色的发型、比例、服装、饰品与背景均以该图为设计事实。
- 目标是从同一角色的连续绕行视频中截取其余三向，而不是让图像模型分别猜测侧面与背面。
- 用户接受视频原生分辨率的截图；这不是高分辨率四视图制作方法。

## 第 1 步：生成最短 Turbo 环绕视频

使用 Runware 的 `minimax:h3@max-turbo`：

- 最短输出时长为 5 秒。
- 480P 是最低分辨率档；若用户未指定清晰度且目标是最低成本的方向提取，可用它。
- 该模型使用 `inputs.frameImages` 提供单张首帧，而不是 `referenceImages`。
- 使用 `deliveryMethod: "async"`、`waitForCompletion: true`、`includeCost: true`。
- 建议 `settings.promptExpansion: "disabled"`，防止平台改写精确的镜头时间要求。

### 镜头轨迹必须写成数值

5 秒完整一圈时，匀速角速度为 **72°/秒**。提示词必须直接给出轨迹，不要只写“环绕一圈”：

```text
The CAMERA, not the character, completes one continuous clockwise 360-degree orbit
at a fixed radius and exactly 72 degrees per second for 5.00 seconds.

0.00s: front (0°)
1.25s: first 90° side profile
2.50s: exact 180° rear view
3.75s: second 90° side profile
5.00s: front again (360°)
```

同时明确以下事实：

- 人物是静止的三维对象；不能转头、眨眼、呼吸、换重心、移动手脚。
- 头发、兔耳、蝴蝶结、衣物、吊带、吊牌、金属件和鞋子均不能自行运动。
- 只能是相机运动；不得用角色转身、缩放、剪辑、跳帧、加减速或摇晃替代。
- 饰品必须始终固定在同一服装连接点，并随相机视角遵守遮挡关系；不得漂浮、穿过手臂或换边。
- 发型要求使用具体的结构描述：主体后发是连贯、厚实、顺滑而有起伏的发量；只有外轮廓、发梢与少量飞散边缘分成细束。不要用泛化的 `lock` 词堆叠代替结构说明。
- 保持基准图原有的纯黑背景；不添加场景、地面、道具、文字或水印。

## 第 2 步：先验证视频，而不是直接截帧

视频生成成功不等于满足绕行要求。先检查：

1. 镜头是否从正面连续经过两侧与背面，并在末尾回到正面。
2. 人物及衣物饰品是否保持静止，而不是被模型自行改形、漂移或动画化。
3. 若视频没有完整绕行或人物发生变化，不把它当作方向图来源；不要仅因提示词中写了 360° 就宣称成功。

## 第 3 步：少量局部候选帧，精确找方向

不要导出每一帧，也不要直接使用名义时间点。

1. 先在 `1.25s`、`2.50s`、`3.75s` 附近各取少量粗候选，例如前后约 `0.25s` 的 7 帧。
2. 把所有粗候选合成**一张内部接触表**检查，而不是逐张查看大量图片。
3. 选出两张真正最接近正侧的帧，记录其帧号或时间。
4. 正背面的理论位置取两个已确认侧面帧的中点：

```text
rearFrame = (firstSideFrame + secondSideFrame) / 2
```

5. 只围绕该中点检查少数连续帧，例如中点前后各 2 帧；从中选择最接近 180° 正背面的帧。
6. 只有对齐的帧才输出；近似侧面、近似背面直接删除。若局部候选中没有正背面，不要硬保留一张，必须重新生成视频或改用其他工作流。

### 方向判断

- 正侧：只应呈现单侧脸部轮廓、单侧肩线与单侧胸／髋轮廓；不能残留明显正面双肩、双胸或正脸。
- 正背：背部轮廓、双腿与双靴的透视必须处于直后方；不能以轻微斜背冒充正背。
- 为避免误标，可按画面事实命名为 `profile-facing-left` 与 `profile-facing-right`，不要在无法确认角色解剖左右时擅自标为“左侧／右侧”。

## 输出命名

保留原视频；只输出确认对齐的帧，例如：

```text
mirta-h3-max-turbo-orbit-profile-facing-left.png
mirta-h3-max-turbo-orbit-back-view.png
mirta-h3-max-turbo-orbit-profile-facing-right.png
```

不要把临时接触表、未对齐候选或失败视频混入正式方向图目录。

## 限制

- 单首帧加文本不能保证模型严格遵循相机路径；数值化轨迹只会提高遵循概率。
- 480P 视频截图适合确认方向与遮挡关系，不应被误认为原生高分辨率角色设定图。
- 对需要高精度服装背面、发型拓扑或饰品连接关系的资产制作，应以确认过的方向截图为依据进一步制作，不能把模型臆造的背面细节当作原设事实。
